Rework what you're about to send an LLM into something denser and structurally clearer — same meaning, fewer tokens, easier to parse correctly.

Settings — your API key

Distill calls the Claude API directly from your browser with this key. Nothing is sent to any server run by Distill — there isn't one. You pay Anthropic directly for what you use; a single pass typically costs a small fraction of a cent to a few cents depending on the model below. Counting tokens (the before/after numbers) uses a separate, lightweight endpoint that doesn't generate any text.

Token counts are model-specific — switching models may change the before/after numbers even for the same text.

What this does, and doesn't, promise

Distill cuts redundancy, filler, and unnecessary hedging, and makes the actual point or request explicit — while keeping full grammatical sentences. It doesn't use shorthand, symbols-for-words, or dropped grammar to save space, because pushing text away from normal language can make it less reliably understood even while cutting tokens, which defeats the point.

Numbers, names, dates, and negations ("not", "never", "no") are meant to be preserved exactly. If something else might have shifted meaning during the rewrite, it's flagged instead of silently smoothed over.

Token savings scale with how much redundancy was actually in the original — concise input won't shrink much, and that's expected, not a failure.

This is a one-off, stateless tool: nothing about your writing is learned or remembered between messages. Only your API key is stored, only in this browser, only on this device, and only until you clear it.
